# Noto Sans SC

The bundled PDF fallback font is sourced from Google Fonts and subset to
GB2312 Chinese characters, ASCII and common punctuation:

- Upstream: https://github.com/google/fonts/tree/main/ofl/notosanssc
- License: SIL Open Font License 1.1

The full license text is included in `OFL.txt`.

The Flutter interface uses the iOS system Chinese fonts (`PingFang SC` and
`Songti SC`) so the app does not need to bundle fonts used only for UI text.
